# 晶圆熔丝阵列复核器

受污染熔丝阵列照片的浏览器复核器：用户粘贴 JSON 描述（高/宽、每行每列熔断数、已知
0/1 位、相邻 2×2 区块的奇偶校验），核心为**自行实现的传播 + 回溯求解器**，在浏览器内
完成判定与证据呈现。纯静态前端，**无业务后端、无任何外部请求**。

## 技术栈

TypeScript · React 18 · Vite 5 · SVG · Vitest · Playwright（Chromium）· Docker Compose

## 输入格式

```json
{
  "height": 4,
  "width": 4,
  "rowCounts": [1, 2, 1, 3],
  "colCounts": [1, 2, 2, 2],
  "known": [[0, 0, 1]],
  "blocks": [[1, 1, 1]]
}
```

| 字段 | 约束 |
| --- | --- |
| `height` / `width` | 整数，1..18 |
| `rowCounts` | 长度 = `height`，每项为 0..`width` 的整数（行熔断数） |
| `colCounts` | 长度 = `width`，每项为 0..`height` 的整数（列熔断数） |
| `known` | `[r, c, v]`；坐标从 0 开始、不得越界；`v` ∈ {0,1}；坐标互不重复且不得冲突 |
| `blocks` | `[r, c, p]`；2×2 区块左上角，覆盖 `(r,c),(r+1,c),(r,c+1),(r+1,c+1)`，必须完整落盘（`r≤H-2, c≤W-2`）；区块不重复；`p` 为四位异或结果 ∈ {0,1} |

行/列熔断总量不等不是输入错误——它会被求解器判为 `impossible`。

校验器会把**所有可独立判定的错误一次性列全**（缺项、计数越界、重复坐标、已知位冲突、
区块越界等），并在页面上清除上一次证据；任何一项非法都不进入求解。

## 判定语义与求解器

解以**行优先位串**表示，并按 **0 < 1** 的字典序枚举：

- **`impossible`（零解）**：显示 impossible，**隐藏矩阵**；
- **`unique`（一解）**：显示 unique，展示唯一矩阵；
- **`ambiguous`（多解）**：显示 ambiguous，**仅展示字典序最小的两个解**，
  给出首差位置与见证位串（两解共同前缀 + 分叉位置 0，其余 `?` 未定），
  两解首个差异格红色高亮，可在两个页签间切换对照。

求解器（`src/lib/solver.ts`）要点：

- **基数约束传播**：剩余需求 < 0 或 > 剩余未定位格即矛盾；需求为 0 时余格全置 0，
  与未定位格数相等时全置 1（行、列双向）；
- **四位异或约束传播**：已定位奇偶与 `p` 不符即矛盾；仅剩 1 个未知格时唯一确定其值；
- **回溯**：始终选择行优先的第一个未知格，先试 0 再试 1（保证解序）；
- **找到两个解立即停止，绝不枚举全部解**；18×18 无约束盘面也只访问极少量节点。

页面以 SVG 呈现矩阵与每行/列的需求与剩余量；点击右侧任一行/列/已知位/区块约束会
联动高亮其单元，点击单元也会反选所属约束（区块优先，其次已知位，再次整行）。

## 本地开发

```bash
npm ci
npm run dev        # 开发服务器
npm run test       # Vitest 单元测试
npm run build      # 类型检查 + 生产构建
npm run e2e        # Playwright（自动 build 并拉起 preview）
```

## Docker

构建仅需常规网络（npm/Playwright 浏览器下载发生在构建期）；**运行中的 Web 容器不发起
任何外部请求**——运行镜像不含 npm 依赖，仅用 Node 内置模块写的零依赖静态服务器
（`server/static-server.mjs`）托管 `dist/`。

```bash
# Web：宿主端口由 WEB_PORT 覆盖（默认 8080），容器内固定 4173
WEB_PORT=9090 docker compose up --build web

# 一次性验收服务：Vitest + 构建 + Playwright，结束即退出，码 0 为通过
docker compose build verify
docker compose run --rm verify
```

## 验收夹具（均已用朴素全枚举交叉验证）

- **深层唯一解**：4×4、5 个区块，唯一解 `0010100101000111`，需 4 层分叉；
  去掉区块后不唯一，证明是异或约束锁定了解。
- **晚分叉多解**：共 10 个解，求解器只保留字典序最小两个
  `0001011000101101` / `0001011001001011`，前 9 位相同，首差固定在 idx 9 即 (2,1)。
- **传播后矛盾**：与唯一解夹具仅差一个区块的奇偶翻转，单行/列基数各自自洽，
  矛盾在 4 层分叉后的传播中暴露。
- **混合非法输入**：一次列全长度不符、计数越界、重复坐标、已知位冲突、区块越界，
  并清除旧证据。

单元测试另含 300 个随机小实例与朴素全枚举的逐项对照（状态、字典序前两解、首差、见证），
以及 18×18 盘面的“不枚举全部解”性能断言。
